健檢報告上的 GOT、GPT 出現紅字，即使沒有任何不舒服，也難免擔心自己是不是得了肝炎。其實，肝指數異常是一個需要找原因的訊號，而不是疾病診斷。

## GOT、GPT 到底在測什麼？

GOT 和 GPT 是存在於細胞內的酵素。細胞受到傷害時，這些酵素可能釋放到血液中，因此抽血數值會升高。[來源:alt-ast-ref1][來源:alt-ast-ref2]

| 健檢名稱 | 現行英文縮寫 | 主要來源與意義 |
| --- | --- | --- |
| GOT（麩胺酸草醋酸轉胺酶） | AST | 肝臟、骨骼肌、心肌等，並非肝臟專屬 |
| GPT（麩胺酸丙酮酸轉胺酶） | ALT | 以肝臟為主要來源，較能反映肝細胞受傷 |

**肝細胞受傷不等於肝臟失去功能。** 要判斷肝臟是否仍能正常製造蛋白質、凝血因子及處理膽紅素，還需要其他檢驗，例如白蛋白、凝血時間（PT/INR）與膽紅素。這些數值也可能受到其他疾病影響，必須綜合判讀。[來源:alt-ast-ref1][來源:alt-ast-ref2]

## 肝指數多高才需要擔心？

先查看報告上的正常值上限，而不是只看紅字。不同醫院、檢驗方式及性別的參考範圍可能不同。[來源:alt-ast-ref1]

下表以正常值上限為 40 U/L 示範，採用美國胃腸病學會的升高幅度分類。就醫時效是供民眾參考的保守分流建議，並非單靠數字即可決定的固定規則。[來源:alt-ast-ref1][來源:alt-ast-ref2]

| 升高幅度 | 示範數值（U/L） | 建議行動 |
| --- | ---: | --- |
| 超過上限但未達 2 倍 | >40 至 <80 | 若無症狀，可近期安排門診 |
| 2 倍至未滿 5 倍 | 80 至 <200 | 儘早門診評估，不宜只等待下次健檢 |
| 5 至 15 倍 | 200–600 | 當日聯繫醫療院所接受評估 |
| 超過 15 倍 | >600 | 當日緊急評估，通常宜至急診 |

數值較高不必然代表永久性傷害較嚴重。例如急性肝炎可能造成非常高的數值，卻有機會完全恢復；慢性肝病即使數值只有輕微變化，也可能已出現纖維化（肝臟結疤）。[來源:alt-ast-ref1][來源:alt-ast-ref3][來源:alt-ast-ref4]

## 為什麼 GOT、GPT 會升高？

| 可能原因 | 有哪些線索？ |
| --- | --- |
| 代謝相關脂肪肝（MASLD） | 腰圍過大、糖尿病、血脂異常；體重正常者也可能發生 |
| B、C 型肝炎 | 可能長期沒有症狀，須靠病毒相關檢驗辨認 |
| 飲酒相關肝損傷 | 長期大量飲酒或近期大量飲酒 |
| 藥物或保健品相關肝損傷 | 新增藥物、中草藥、減重或健身補充品後出現異常 |
| 肌肉受傷或劇烈運動 | 近期重量訓練、長跑、肌肉疼痛，尤其 GOT 偏高時 |
| 急性感染或膽道疾病 | 發燒、噁心、右上腹痛、黃疸等 |
| 較少見的疾病 | 自體免疫性肝炎、鐵質堆積、威爾森氏症等 |

上述線索只能協助縮小範圍，不能直接確診；同一個人也可能同時有多種原因。[來源:alt-ast-ref1][來源:alt-ast-ref2][來源:alt-ast-ref3]

## 肝指數異常，需要做哪些檢查？

### 第一步：確認異常與近期可能原因

就診時請帶歷次健檢報告、所有用藥與保健品清單，並告知醫師飲酒量、最近是否生病、出國、劇烈運動，以及是否曾感染肝炎。

醫師會依情況重新抽血確認變化，並同步安排病因檢查，而不是反覆驗肝指數直到正常才停止。[來源:alt-ast-ref1][來源:alt-ast-ref4]

### 第二步：依風險選擇必要檢查

| 檢查 | 主要目的 |
| --- | --- |
| GOT、GPT | 確認數值變化 |
| ALP、GGT | 協助辨認膽道或其他肝膽異常 |
| 膽紅素、白蛋白、PT/INR | 評估排泄及合成功能，特別是明顯或急性異常時 |
| 全血球計數（含血小板） | 提供感染、血球及慢性肝病相關線索 |
| B 型肝炎表面抗原（HBsAg）、C 型肝炎抗體（anti-HCV） | 初步辨認病毒性肝炎；C 肝抗體陽性須再驗 HCV RNA 確認是否仍感染 |
| 腹部超音波 | 尋找脂肪肝、膽道阻塞或肝臟結構異常 |
| 血糖、血脂 | 評估代謝相關風險 |

不一定每個人都要一次完成所有項目。遇到肌肉症狀可加驗肌酸激酶（CK）；原因不明時，可能再檢查鐵蛋白、轉鐵蛋白飽和度、自體免疫抗體等。急性明顯升高時，需依暴露史評估 A、B、C、E 型肝炎及其他急性病因。[來源:alt-ast-ref1][來源:alt-ast-ref2][來源:alt-ast-ref4]

### 第三步：必要時評估肝臟纖維化

若有脂肪肝、糖尿病或長期肝指數異常，醫師可能利用年齡、GOT、GPT 和血小板計算 FIB-4，初步判斷肝臟結疤的風險。必要時再安排肝臟彈性檢查。一般腹部超音波無異常，仍不能完全排除早期纖維化。[來源:alt-ast-ref3][來源:alt-ast-ref4]

單次輕微紅字通常不需要直接安排電腦斷層、核磁共振或肝臟切片；這些檢查應依特定臨床疑問選擇。

在適合接受 MASLD 纖維化評估的成人，常用 1.3 作為進一步風險分層的界值，超過 2.67 提示較高風險；65 歲以上低風險界值通常改為 2.0。35 歲以下辨識能力較差；急性肝損傷期間不宜用來判定慢性纖維化。分數不是確診，應按風險安排彈性檢查等後續評估。[來源:alt-ast-ref3]

### 台灣有免費 B、C 型肝炎篩檢嗎？

依國健署 2026 年 11 月 27 日公告，民國 75 年（1986 年）含以前出生、未滿 80 歲且尚未接受該項篩檢的民眾，可使用終身一次公費 B、C 型肝炎篩檢。[來源:alt-ast-ref5]

若不符合公費資格，但已有肝指數異常或感染風險，仍可由醫師依病情安排診斷性檢驗，不必等到符合篩檢年齡。

## 肝指數過高，需要吃藥嗎？

**治療目標是處理造成傷害的原因，而非單純消除健檢紅字。**

代謝相關脂肪肝以改善代謝與生活習慣為基礎；B 型肝炎須依病毒量、肝臟狀況及其他條件決定是否用藥；確認有 C 型肝炎病毒感染者通常可接受抗病毒治療。疑似藥物性肝損傷則應由醫師判斷是否調整或停止可疑藥物。[來源:alt-ast-ref2][來源:alt-ast-ref3][來源:alt-ast-ref5]

沒有適用於所有肝指數異常者的通用保肝藥。不建議為降低數字自行購買排毒產品或草藥。

## 現在可以做什麼？

1. 暫停飲酒，直到病因釐清。若長期大量飲酒或曾有戒斷症狀，應尋求醫療協助安全戒酒。
2. 暫停非必要的草藥及保健補充品；處方藥先與開藥醫師討論，不宜自行停藥。
3. 避免過量使用含乙醯胺酚（acetaminophen，例如普拿疼成分）的止痛藥，注意複方感冒藥可能含相同成分。疑似過量應立即就醫。
4. 若有過重或脂肪肝，採取可持續的飲食與運動調整，減少含糖飲料，並管理血糖與血脂。對過重的 MASLD 成人，減重至少 5% 有助減少肝脂肪，7–10% 有助改善肝臟發炎，至少 10% 有機會改善纖維化；並非每個人都必須減重。[來源:alt-ast-ref3]
5. 若近期曾進行不習慣的高強度運動，告知醫師，複檢前依建議暫緩此類運動，不必因此長期停止一般運動。

## 什麼時候需要就醫？多久複檢？

若出現新發黃疸（眼白或皮膚變黃）、意識混亂、異常嗜睡、明顯出血、嚴重腹痛、發燒合併黃疸、持續嘔吐或疑似藥物過量，應當日緊急就醫；意識異常或大量出血請立即前往急診或撥打 119。[來源:alt-ast-ref1][來源:alt-ast-ref2]

沒有警訊的輕微異常，可先到家醫科或肝膽腸胃科。若有明確暫時性誘因、其他檢查無警訊，醫師可能在數週內安排複檢，例如 2–4 週；這是實務上的示例，並非所有患者適用的指引期限。若數值持續上升、病因不明或出現纖維化風險，應提早進一步評估或轉診。[來源:alt-ast-ref1][來源:alt-ast-ref4]

若已確診慢性肝病，後續追蹤應依病因及疾病分期安排，不能只以 GOT、GPT 恢復正常作為停止追蹤的依據。

## 進階實證

> [!DEEPDIVE] 正常值上限與健康參考值有何不同？
>
> ACG 2017 指引提出，經過健康族群篩選的 ALT 參考上限男性約 29–33 U/L、女性約 19–25 U/L。這與部分實驗室採用的參考區間不同。這些數字是提示應評估的參考，而非診斷肝炎或啟動藥物的門檻。[來源:alt-ast-ref1]

> [!DEEPDIVE] AST/ALT 比值與 R ratio 的臨床價值
>
> AST/ALT 大於 2 可提示酒精相關肝損傷，但並非特異性診斷；進展性纖維化及肌肉來源亦可影響比值。R ratio 則是另一個指標：R = (ALT / ALT 正常上限) ÷ (ALP / ALP 正常上限)。常用於區分肝細胞型（R ≥ 5）、膽汁鬱積型（R ≤ 2）及混合型（2 < R < 5），尤其在疑似藥物性肝損傷時有用。應配合採血時點與臨床情境判讀。[來源:alt-ast-ref1][來源:alt-ast-ref2]

> [!DEEPDIVE] FIB-4 如何計算與解讀？
>
> FIB-4 = 年齡（歲）× AST（U/L）÷〔血小板（10⁹/L）× √ALT（U/L）〕。

> [!DEEPDIVE] 為什麼不能只靠定期抽血排除肝病？
>
> 2026 年英國胃腸病學會更新疑似肝病評估指引，將代謝風險、飲酒風險與非侵入性纖維化評估納入基層照護路徑。這反映臨床重點由單純尋找肝指數異常，轉向辨識可能進展的慢性肝病。此類診斷路徑主要依據診斷研究、觀察性研究及指引整合，並不代表每一項檢查都已有隨機試驗證明可降低死亡率。[來源:alt-ast-ref4]
