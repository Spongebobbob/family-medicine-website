健檢報告上的尿液潛血（Occult blood、OB 或 BLO）出現紅字，即使尿液看起來完全正常，也值得確認原因。不過，第一次驗到潛血陽性，不代表腎臟已經受損，更不代表一定罹患癌症。

下一步通常不是立刻做電腦斷層，而是確認尿液中是否真的有紅血球。

## 尿液潛血陽性，就是血尿嗎？

**不一定。尿液試紙與顯微鏡檢查測量的是不同的東西。** 試紙對血紅素及肌紅素也會產生反應，因此即使沒有完整紅血球，也可能呈現陽性。

| 健檢項目 | 報告常見寫法 | 如何理解 |
| --- | --- | --- |
| 尿液潛血 | Occult blood、BLO、trace、1+ 至 3+ | 試紙反應強度，不能直接換算成紅血球數量 |
| 尿液紅血球 | RBC、RBC/HPF | 顯微鏡高倍視野下的紅血球數量 |
| 肉眼血尿 | Gross hematuria | 肉眼可見尿液呈血色，需確認是否真的出血 |

依美國泌尿科醫學會（AUA）2025 年更新指引，一次正確採集的尿液檢體，若顯微鏡下每個高倍視野有至少 3 顆紅血球（≥3 RBC/HPF），即可作為顯微血尿的判定門檻。[來源:urine-ob-ref1][來源:urine-ob-ref2]

如果試紙陽性，但紅血球低於門檻，通常尚不能確診顯微血尿。醫師會依試紙反應強度、採檢品質、症狀及個人風險，決定是否重新驗尿。

## 為什麼會有血尿？

血尿可能來自腎臟、輸尿管、膀胱或尿道，也可能是採檢時混入外部血液。以下線索有助於安排下一步，但不能單靠症狀確定病因。

| 可能原因 | 常見線索 |
| --- | --- |
| 月經或陰道出血污染 | 採檢時正值出血期間 |
| 劇烈運動後短暫血尿 | 長跑、高強度訓練後出現 |
| 尿路感染 | 排尿灼熱、頻尿、尿急，有時發燒 |
| 尿路結石 | 側腰痛、陣發性疼痛，亦可能完全無症狀 |
| 攝護腺肥大等良性疾病 | 尿流變細、排尿困難或夜尿 |
| 腎絲球疾病 | 蛋白尿、水腫、高血壓或腎功能異常 |
| 泌尿道腫瘤 | 可能完全不痛，尤其需留意年長者及吸菸者 |

**沒有疼痛並不能排除重要疾病。** 但也不必因為一次血尿就認定是癌症；檢查應依個人的風險安排。[來源:urine-ob-ref1][來源:urine-ob-ref3]

## 第一次驗到尿液潛血，下一步怎麼做？

### 第一步：確認檢體與紅血球數量

若沒有急症警訊，可以先掛家庭醫學科或泌尿科，攜帶完整健檢報告。若原本只做試紙檢查，應補做尿液沉渣或顯微鏡檢查。

重新採檢時，可避開月經及劇烈運動後的時段，以清潔中段尿採集：先清潔外部、排掉前段尿，再用檢體容器接取中段尿。正常飲水即可，不必刻意大量喝水稀釋尿液。

### 第二步：評估腎功能及其他異常

| 檢查 | 何時需要、能回答什麼問題 |
| --- | --- |
| 尿液常規與沉渣 | 確認紅血球、白血球及其他異常 |
| 血壓、血清肌酸酐與 eGFR | 確認顯微血尿後的基本評估，了解腎功能及高血壓情況 |
| 尿液白蛋白／肌酸酐比值（uACR）或蛋白／肌酸酐比值（uPCR） | 有蛋白尿或懷疑腎臟疾病時，定量尿蛋白 |
| 尿液細菌培養 | 懷疑尿路感染時，協助確認病原及用藥 |

如有明顯蛋白尿、異形紅血球、紅血球圓柱體或腎功能不佳，應考慮腎臟科評估；是否同時需要泌尿科檢查，仍依腫瘤風險決定。[來源:urine-ob-ref1][來源:urine-ob-ref3]

### 第三步：決定是否需要影像或膀胱鏡

不是所有人都需要做侵入性檢查。以下適用於已確認顯微血尿、且沒有尚待處理的明確暫時性原因的成人。[來源:urine-ob-ref1][來源:urine-ob-ref2]

| 風險分層 | 建議下一步 |
| --- | --- |
| 低或極低風險 | 6 個月內複驗尿液，通常不用立即做超音波或膀胱鏡 |
| 中度風險 | 通常安排膀胱鏡及腎臟、膀胱超音波 |
| 高風險 | 通常安排膀胱鏡及泌尿道電腦斷層攝影（CT urography），不適合注射顯影劑者另選檢查 |

例如，一位 30 歲、不吸菸、沒有其他危險因子且尿液只有少量紅血球的成人，可能先複驗即可；相反地，年長、長期吸菸或曾有肉眼血尿的人，即使沒有不適，也可能需要完整泌尿道評估。

## 超音波正常，還需要做膀胱鏡嗎？

**有時仍然需要，因為兩種檢查的用途不同。**

| 檢查 | 優點 | 主要限制 |
| --- | --- | --- |
| 腎臟及膀胱超音波 | 無輻射，可評估腎臟腫塊、積水等 | 可能漏掉小型病灶及輸尿管病變 |
| 膀胱鏡 | 直接觀察膀胱內壁 | 侵入性，可能短暫疼痛、出血或感染 |
| 泌尿道電腦斷層（CTU） | 詳細評估腎臟、輸尿管及泌尿道病灶 | 有輻射，通常需含碘顯影劑，可能出現偶發發現 |

一般腹部電腦斷層、結石用無顯影劑電腦斷層與 CTU 的用途不同，不能一概互相取代。尿液細胞學及腫瘤標記也不是每個人都需要接受的常規檢查。[來源:urine-ob-ref1][來源:urine-ob-ref3]

## 需要吃藥嗎？多久要再驗尿？

單純的尿液潛血陽性沒有特定藥物可以治療，治療應針對病因。例如有症狀的細菌感染可能需要抗生素，結石則依大小、位置及是否阻塞決定處理方式。不要只為了讓健檢紅字消失而自行服用抗生素或止血藥。

| 情況 | 追蹤方式 |
| --- | --- |
| 月經污染或其他暫時性因素 | 因素解除後重新採檢 |
| 尿路感染或其他已處理的良性原因 | 症狀或原因解除後再驗尿；指引討論建議約 3 週至 3 個月內確認是否消失 |
| 已確認顯微血尿且屬低風險 | 6 個月內複驗；仍有血尿則重新分層 |
| 已完成適當泌尿科檢查且無異常 | 與醫師共同決定是否再驗尿；後續驗尿正常時通常可停止專為血尿安排的追蹤 |

上述時程不適用於出現警訊或其他需要立即處理的疾病。若已知有慢性腎臟病，仍須依腎臟病本身的照護計畫追蹤。[來源:urine-ob-ref1][來源:urine-ob-ref2]

## 哪些情況需要儘快就醫？

- **立即至急診：** 血塊造成尿不出來、大量血尿合併頭暈或昏厥、發燒畏寒合併側腰痛，或嚴重肌肉疼痛伴深色尿及尿量減少。
- **儘速安排門診：** 肉眼可見血尿（即使只有一次或完全不痛）、持續顯微血尿、蛋白尿、腎功能下降，或新出現的排尿症狀。

若目前只是無症狀的健檢潛血陽性，通常可以先安排一般門診完成確認，不需要直接跑急診。

>

>
> 2025 修訂特別調整女性的年齡門檻，避免僅因年齡將女性列為高度風險。指引所整理的驗證研究中，各層惡性腫瘤檢出比例約為低風險 0–0.4%、中度 0.2–3.1%、高度 1.3–6.3%。這些是研究族群的檢出比例範圍，不是個人終生風險，也未必能直接套用於台灣人口。[來源:urine-ob-ref1]

> [!DEEPDIVE] 為何不對每個人做 CTU？
>
> Waisbrod 等人在 2021 年發表的系統性回顧與統合分析評估顯微血尿族群接受膀胱鏡與 CTU 的癌症診斷效益。研究採觀察性資料，顯示上泌尿道癌症的整體檢出效益偏低，支持依風險選擇影像檢查，而不是普遍使用 CTU。[來源:urine-ob-ref4] 這類研究不能直接證明某一檢查策略可以降低死亡率。

> [!DEEPDIVE] 尿液腫瘤標記的角色
>
> 中度風險且充分理解漏診風險、希望避免膀胱鏡的患者，可與泌尿科討論尿液細胞學或經驗證的尿液腫瘤標記；仍須接受超音波。若因此未做膀胱鏡，應在 12 個月內複驗尿液，持續血尿者應接受膀胱鏡。高度風險者不應以陰性標記取代膀胱鏡。特殊情境如持續血尿合併刺激性症狀且懷疑原位癌，可考慮細胞學。[來源:urine-ob-ref1][來源:urine-ob-ref3]
