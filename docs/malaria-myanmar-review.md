# 緬甸海拔選項簡化

查核日期：2026-11-26；臨床審閱仍為 pending。

來源：[NaTHNaC 緬甸國別頁](https://travelhealthpro.org.uk/countries/myanmar-burma#Malaria)。官方將低於 1000m 列為應考慮 AP／Doxycycline 的區域，高於 1000m 列為低風險，一般旅客以防蚊與症狀警覺為主；特殊族群須個別評估。原文沒有明列正好 1000m 的歸類，不將其擴成「大於或等於」。

原介面要求選擇海拔分區後再次輸入最低海拔；選擇高於 1000m 卻填入 1000，會被嚴格邊界檢查判為資料不足。現改為選項直接確認海拔分類，移除緬甸兩區的重複數值欄位與檢核，並新增正好 1000m／無法確認分區選項，提供具體待確認原因。其他國家的海拔檢核維持原規則。

回歸驗證包含無數值即可判定高／低海拔區、舊數值不覆蓋選項、AP／Doxycycline 候選、特殊族群，以及邊界與未知仍不得產生用藥方案。
